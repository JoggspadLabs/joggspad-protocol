03 — Design

Three moves.
One discipline.

Fair openings

A launch begins with a published curve and a fixed window. No private allocation sits ahead of the crowd, and the curve can be read before anyone commits a coin.

Curve
Published up front
Window
Fixed at creation
Allocation
Public first

Release on schedule

Team and treasury units unlock in steps tied to block height rather than to a promise. Each step is an on-chain event that anyone can audit afterward.

Trigger
Block height
Cliff
Set per launch
Audit
Public events

Ceilings, not trust

Every wallet that moves funds for a launch carries a daily cap, a monthly cap and an allow list. Crossing a line pauses the action until a human signs.

Caps
Per day, per month
Scope
Allow list only
Override
Human sign-off

06 — Guards

Limits written
into the rails.

Controls are part of the launch itself, not a layer someone bolts on afterward.

Spend ceilings

Each wallet gets a limit that resets by day and by month. A transfer beyond it sits parked until someone signs.

Allow list

Only named destinations can receive funds. Each call gets screened ahead of departure.

Freeze

One switch stops treasury movement inside the block it is thrown.

Ledger

Each transfer, refusal and rule change lands in a public record, hash included.
